📘 Description:
This is a next-generation stock portfolio tracker built using Python.
It allows users to enter multiple stock names, their prices, and quantities,
and automatically calculates the total portfolio value.

✨ Features:
- User-friendly interactive CLI design
- Clean and modern layout with emojis
- Input validation (no crashes on wrong input)
- Dynamic portfolio summary and total calculation
- Professional-grade console formatting
